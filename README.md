# 火焰检测系统

## 项目介绍

这是一个基于YOLOv8的火焰检测系统，能够实时检测图像和视频中的火焰，并对火焰类型进行分类。系统提供了完整的训练、验证和推理流程，以及一个基于PyQt5的图形用户界面，方便用户进行操作。

## 功能特性

- ✅ 支持多种火焰类型检测（扩散火焰、预混火焰、不完全预混火焰、异常火焰）
- ✅ 数据集预处理与自动划分（训练集、测试集、验证集）
- ✅ YOLOv8模型训练与优化
- ✅ 模型验证与性能评估
- ✅ 图片上传检测
- ✅ 摄像头实时检测
- ✅ 基于PyQt5的友好图形界面

## 技术栈

- Python 3.8+
- YOLOv8 (Ultralytics)
- PyQt5
- OpenCV
- NumPy
- YAML

## 快速开始

### 环境准备

1. 安装Python 3.8或更高版本
2. 安装依赖：

```bash
pip install -r requirements.txt
```

### 数据集获取

由于数据集较大，无法直接包含在GitHub仓库中，您可以通过以下方式获取：

- 百度网盘链接：`https://pan.baidu.com/s/1iW9_fdv-PcpE7oehU1_POQ?pwd=tzej`
- 提取码：`tzej`

下载完成后，解压并将`dataset`放入项目根目录中。

### 数据预处理

1. 将原始火焰数据集放入`火焰数据集`目录
2. 运行数据预处理脚本：

```bash
python 01_data_preprocess.py
```

该脚本将：
- 划分数据集为训练集(70%)、测试集(20%)和验证集(10%)
- 创建`dataset`目录并整理数据
- 生成`data.yaml`配置文件

### 模型训练

运行训练脚本：

```bash
python 02_train.py
```

训练参数说明：
- 预训练模型：YOLOv8n
- 训练轮数：30
- 批次大小：4
- 学习率策略：余弦学习率
- 数据增强：mixup=0.2, copy_paste=0.3

### 模型验证

运行验证脚本：

```bash
python 03_val.py
```

### 推理

运行推理脚本：

```bash
python 04_infer.py
```

### 图形界面

运行PyQt5界面：

```bash
python 05_pyqt_interface.py
```

界面功能：
- 打开摄像头实时检测
- 上传图片进行检测
- 显示检测结果和系统资源信息

## 火焰类型

系统支持检测以下四种火焰类型：

1. **扩散火焰**：燃料与氧化剂在燃烧区混合的火焰
2. **预混火焰**：燃料与氧化剂在燃烧前充分混合的火焰
3. **不完全预混火焰**：过渡状态的火焰
4. **异常火焰**：熄灭过程中的火焰

## 模型改进

项目包含模型改进分析文档：

## 注意事项

1. 确保有足够的显存用于训练（建议8GB以上）
2. 训练时间取决于硬件配置，通常需要数小时
3. 首次运行时需要下载YOLOv8预训练模型
4. 数据集路径需要根据实际情况调整
